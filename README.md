# VRTI Avatar Menu

This repository contains the package listing for the VRTI (VR Treadmill Interface) VRChat Avatar Menu prefab.

For the main package listing, and how to install this package, please visit: [https://vcc.raphii.co](https://vcc.raphii.co)

More information about VRTI and this avatar menu can be found here: [https://raphii.co/vrti/getting-started/vrchat--osc-control/](https://raphii.co/vrti/getting-started/vrchat--osc-control/)
